Rules

Short, and checked by python3 design/tools/tokens.py --check where a machine can check them.

Brass is the only accent.Links, the running status and the selected tab line use accent. The primary button is ink on light and brass on dark.
Good, bad and warn only mean a state.Success, failure, waiting. Never decoration, never a category. Context is the one use of good as a basic, and it stays a mark, not a status.
Status is never colour alone.Every status and outcome has a word, and a status has its own icon shape.
Control outlines use line2.line is for dividers between rows and sections. A button, input or chip outline is line2.
Light and dark are both designed.Every board has a light drawing and a generated dark twin. Neither is an afterthought.
Boards use tokens only.var(--token) and the type classes. A raw colour is a finding; the one exception is a third-party logo marked data-keep.
