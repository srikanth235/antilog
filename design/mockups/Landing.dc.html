Security and control

Answers for your security team, before they ask.

  • Your data stays where it is

    Antilog's server never connects to your data. It keeps ids, numbers and the conversation, never tool output, file contents or diffs.

  • Agents get the least access

    Read-only data credentials that leave out the held-back data, and a short-lived git token that pushes only to the agent's own branch.

  • A person approves what matters

    Adding a credential, raising a budget and opening a pull request ask a person unless your policy pre-approved them. Adding a credential always asks.

  • Everything is in your audit log

    Every change and every approval: who, what, when and the outcome, including our engineers' actions.

  • Your sign-in rules

    Antilog cloud signs in with GitHub or Google. Self-hosted, it uses your own OpenID Connect provider.

  • Your cloud account, when you want it

    Antilog cloud runs on AWS. Self-hosting in your own AWS, Azure or Google Cloud account follows. We act as your data processor, under a data processing agreement.

Questions

What engineering leaders ask us first.

Can't an agent just game the metric?

No. The goal is sealed before work starts. An agent cannot change the evaluation or the protected files, never sees the data held back to confirm a win, and cannot mark its own win. Only the acceptance criteria, as code, decide.

Does this replace my engineers?

No. Agents propose changes and the judge measures them. Your engineers review every pull request and decide what merges, and by the end of the engagement they run Antilog themselves.

Which AI models and agents does it use?

Agents on Claude Managed Agents, AWS AgentCore, the OpenAI Agents API, Microsoft Foundry Agent Service or Google Agent Runtime. Auto picks by measured cost per win on your code and says why. We publish no vendor benchmarks.

How is a win's value decided?

Before work starts, your project owner signs a value model: what one unit of the metric is worth to you a year. It is sealed with the goal, so the number on the receipt and on the invoice is never in dispute.

What do we need to start?

A repo, a metric you already track, read access to the data that measures it, and someone who can say what a gain is worth. We set up the rest with your team.
