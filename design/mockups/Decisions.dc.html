Decisions

The owner's calls, newest first, each dated. A decision here is settled; an open one is a question to put to the owner, not to guess.

Decided16 Nov
Functional Source LicenseRatchet is FSL-1.1-ALv2: public source anyone may self-host, no competing product or service, and each release becomes Apache-2.0 after two years.
Decided16 Nov
The spike measures noiseBeside the plumbing, the spike runs one fixed benchmark many times in fresh judge sandboxes on each judge platform and records the spread, so we know whether Speed experiments can be Kept there.
Decided16 Nov
Paired measurement and the barThe trial and the trial it started from run interleaved in the same fresh judge sandbox. Kept needs the lower confidence bound of the paired gain above zero at 1 − 0.05/k, k being the trials measured in the version, then a paired confirmation and the holdout.
Decided16 Nov
AgentCore firstAgentCore is the first adapter, running agents and the judge sandbox. Claude Managed Agents, the OpenAI Agents API, Foundry and Google Agent Runtime follow.
Decided16 Nov
A thin first releaseSelf-hosted, AgentCore, the web app, one evaluation kind (Speed) with no connectors: seal, measure, Kept, receipt, deliver, budget, approvals and audit. Ratchet cloud, the other adapters, plugins, value models, Return and the Mac app follow.
Decided16 Nov
ratchet mcp in the first releaseAn agent a person already runs gets the Ratchet tools inside a session in the experiment. It pushes trial commits to that session's branch with a short-lived token, and only the judge measures them.
Decided16 Nov
Three aims, beside trustRatchet serves three aims beside the trust rules: cost control (every dollar and token of an experiment is spent well), no tie to one model provider, and Return for the organization.
Decided16 Nov
Value modelsA project owner sets one value model per metric on the project page, with a source. It is sealed with the experiment, so it never changes for that version. An experiment may be sealed with none and then shows No value set. Agents never set or edit a value model.
Decided16 Nov
Auto picks the agentAuto chooses the agent with the best cost per win for the evaluation kind in the project, among the agents the organization turned on, and says why in one line. Before there is data it uses the default agent an owner set. A person can always pick a named agent.
Decided16 Nov
Return counts all spendReturn is Delivered divided by everything spent in the scope, including experiments that found nothing, were stopped or failed. While an experiment is Regressed, the regressed amount moves from Delivered to At risk until a fix is Kept and merged.
Decided16 Nov
Quick check and patience are sealedThe quick check (on or off, default on) and the patience number (default 6) are part of the sealed definition. The quick check never decides Kept. Only the judge runs it.
Decided16 Nov
Two more card kindsKeep going? and Continue on another agent? join the six, so there are eight card kinds. Policy may allow either without asking.
Decided16 Nov
Words for the aimsAgent scoreboard (never leaderboard), Quick check, Keep going?, Hand off, Value model, At risk, Where the spend went, Ideas, Report. Still Return, never ROI; no contract, no run as a noun, no em dashes, no model names or identifiers.
Decided16 Nov
A chat and a judgeRatchet is a chat and a judge. A person talks to a coding agent in a sandbox with repos attached. The judge is a set of tools every session gets: only its numbers count, and only a measured win becomes a pull request. No modes, no plan step, no loop on the server.
Decided16 Nov
Three objectsA session is one agent in one sandbox on one platform, with repos attached. An experiment is a sealed definition of better plus everything measured against it, and a session always belongs to one. A measurement is the judge's signed result for one trial, and a trial is one measure call. Scoreboard, wins, receipts, value and Return are views over measurements.
Decided16 Nov
The toolsEvery session gets seal, measure, history, spawn, deliver and watch, and four setup tools: attach_repo, request_credential, set_environment and request_budget. The same tools are served by ratchet mcp to an agent a person already uses on their own machine. measure returns a ticket and the result arrives later.
Decided16 Nov
Settings are toolsA person approves the tool calls that matter. Setup happens in the chat, when it is needed, as a card. Settings pages list what was approved and revoke it. Two things are still set up in Settings: agent platform accounts, and members with sign-in.
Decided16 Nov
Approval cards and policyEight card kinds: Seal experiment, Raise budget, Add credential, Attach repo, Change environment, Open pull request, Keep going? and Continue on another agent?. Policy per kind is Always ask, Allow up to a limit or Allow. Add credential always asks, because a person types the value into a secure form. Owners and editors approve, viewers approve nothing.
Decided16 Nov
The judge's trust rulesOnly the judge's numbers count. An agent never holds the holdout credential. A sealed experiment never changes. Only the acceptance criteria can mark a win, as one pure function in code. Chat can change what an agent tries and never what counts.
Decided16 Nov
The anti-cheat is in the judgeA sealed experiment; a fresh judge sandbox for every measurement; seal checks before sealing (baseline, noise, planted cheats); confirmation on the holdout before Kept, with a bar that rises with the trials tried; a second opinion from a different provider; and a signed receipt.
Decided16 Nov
What an agent seesThe measured value and guardrail values on the evaluation data, and the outcome. It may read the evaluation's code and may never change it. It never reads the holdout or learns a holdout value. This replaces the earlier rule that an agent never reads the evaluation's code.
Decided16 Nov
Kept, and the eight outcomesA trial is Kept when it beats what it started from by more than the bar, every guardrail holds, and it is confirmed in a fresh judge sandbox and on the holdout. Outcomes: Measuring, Kept, Within noise, Worse, Guardrail failed, Failed holdout, Rejected, Failed.
Decided16 Nov
SessionsOne agent per session, any number of repos, a trial is a set of commits. Git is the hand-off: a short-lived token per repo pushes only to the session's own branch. The agent drives and the server runs no loop. The sandbox is temporary and the conversation is not.
Decided16 Nov
Spawned sessionsA session may spawn others on the same experiment and budget, on any agent and platform. A spawned session cannot spawn. The parent is told when one finishes and a person can open any of them. No agent's vendor is privileged, because only the judge decides.
Decided16 Nov
BudgetsOne budget per experiment, covering all its sessions and their judge time. Spend is model tokens, sandbox time and judge time. A person sets it and can change it at any time, and request_budget asks for more by a card. When it is spent the judge refuses measure and the session is Waiting for you. The organization has a default budget and a monthly cap.
Decided16 Nov
Delivery, watch and memorydeliver opens one pull request per repo changed, each with the receipt, and refuses any trial that is not Kept. The session stays attached to reviews and checks. watch measures again, and a regression wakes a session. history is the memory, failures included.
Decided16 Nov
Ratchet never holds the dataIds, versions, numbers, states, the conversation's words and audit rows only. Never tool output, file contents, diffs or data. Agents' code reads data only inside a platform's sandbox, and the holdout lives only in the judge's credential.
Decided16 Nov
What this replacesNumbered executions became sessions inside an experiment. Drafts, drafting sessions, the config branch and the stepper became cards. Customize, Evaluations, Skills, Plugins, Connectors and Agents pages became setup tools with Settings listing them. Plugins, skill packs, notes, Pause agent, projects and the dashboard page are cut. The three basics became session, judge and organization. Evaluator, evaluator sandbox and measuring platform became judge, judge sandbox and judge platform.
Decided16 Nov
Five agent platformsClaude Managed Agents, AWS AgentCore, OpenAI Agents API, Microsoft Foundry Agent Service, then Google Agent Runtime, in that build order, behind one agent trait with one adapter each. Unchanged. The spike runs on all five before product code.
Decided16 Nov
Ratchet cloud manages the platforms at costOn Ratchet cloud we use our own platform accounts and bill at cost through each experiment's budget. The Agent platforms page is read-only there and shows data and retention per platform. Unchanged.
Decided16 Nov
Self-hosted uses your platform accountsAn owner adds the organization's own accounts under Settings, Agent platforms, with Add platform. Credentials stay in the platform's credential store. Unchanged.
Decided16 Nov
The judge platformThe judge sandbox runs on a platform that can run a command with no agent. AWS AgentCore can. Google Agent Runtime is checked in the spike. The other three cannot. The platform that hosts judge sandboxes carries the Judge platform badge.
Decided16 Nov
Connector credentials are registered onceRead-only, registered once by the customer and kept in the platform's credential store. Ratchet keeps no connector secret and no secret manager reference. Unchanged.
Decided16 Nov
This machine is deferred; no Helm or OpenTofuAgents never run on a Mac, and the Mac app is only a client. Self-hosted is Docker Compose, and Ratchet cloud ships with the Cloudflare config. Unchanged.
