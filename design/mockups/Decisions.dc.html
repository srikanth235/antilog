Decisions

The owner's calls, newest first, each dated. A decision here is settled; an open one is a question to put to the owner, not to guess.

Decided · 16 Nov

Decided16 Nov
Five agent platformsClaude Managed Agents, AWS AgentCore, OpenAI Agents API, Microsoft Foundry Agent Service, then Google Agent Runtime, in that build order. The platform trait is designed against all five from the start, and the end-to-end spike runs on all five before product code.
Decided16 Nov
Agents run as sessions on agent platformsClaude Managed Agents, AWS AgentCore and the OpenAI Agents API. Each agent loops in its own session. Ratchet runs no sandboxes of its own and no runner.
Decided16 Nov
Ratchet cloud manages the platforms at costOn Ratchet cloud we use our own platform accounts and bill at cost through each run's budget. The Infrastructure page is read-only there and shows data and retention per platform.
Decided16 Nov
Self-hosted uses your platform accountsAn owner adds the organization's own accounts under Settings, Infrastructure, with Add platform. Credentials stay in the platform's credential store.
Decided16 Nov
A drafting session, then a runA person and one agent work out a new experiment in a drafting session. It ends by pushing the experiment's files to the config branch. Approve starts one session per agent from that branch.
Decided16 Nov
Measuring happens in an evaluator sandboxAn agent asks to measure with the measure tool. Ratchet measures in an evaluator sandbox with no agent in it, on the experiment's measuring platform, then removes it. Only the evaluator sandbox has the holdout credential.
Decided16 Nov
Connector credentials are registered onceRead-only, registered once by the customer and kept in the platform's credential store. Ratchet keeps no connector secret and no secret manager reference.
Decided16 Nov
This machine is deferredThe Mac app is only a client of the server's API. Agents never run on a Mac. The menu bar extra shows runs and what needs attention.
Decided16 Nov
No Helm or OpenTofu at launchSelf-hosted is Docker Compose. Ratchet creates no clusters or machines, so there is nothing to template for them.

Decided · 15 Nov

Decided15 Nov
Real logos for named productsConnectors, agents, model providers, clouds and sign-in providers show their own real logo from a credible source: the brand's own assets first, then Simple Icons. Never a text tile; on 16 Nov Amazon, Microsoft, OpenAI and xAI got their real logos in place of text tiles. Ratchet's own concepts keep our glyphs.
Decided15 Nov
Postgres self-hosted, SQLite in the cloudOne core, two shells. Self-hosted servers use Postgres, Ratchet cloud uses one SQLite database per organization. Both are supported from day 0.
Superseded15 Nov
Two places work can runYour infrastructure or Ratchet-managed. An owner chooses per organization. Ratchet-managed runs in our sandboxes and is only on Ratchet cloud. Replaced by "Agents run as sessions on agent platforms" on 16 Nov.
Superseded15 Nov
Bring your own model key, or use oursYour own key always works. Ratchet-supplied is only with Ratchet-managed and is billed to the run’s budget. Only the egress proxy adds a key. Replaced by "Agents run as sessions on agent platforms" on 16 Nov.
Decided15 Nov
Agents run the loopEach agent loops in its own session: change, measure, keep or discard. Agents see every trial’s measured value, never the holdout. Each keeps its own lineage and may start from the best trial. The run budget starts as even shares, and an agent stops when it has no gain over its last 8 trials.
Decided15 Nov
A stopped agent passes on its budgetEach agent starts with an even share. When an agent stops early, what it has not spent is split evenly among the agents still iterating. Nothing is taken from an agent that is still iterating, and shares are not weighted by early gains, which are often noise.
Decided15 Nov
Browser supportCurrent and previous Chrome, Edge, Firefox and Safari on desktop. Newly available features only with a light fallback and no polyfill package.
Superseded15 Nov
Radix stays, native where it has nothingRadix for dialog, menu, popover, tabs, tooltip and select, styled by the web guides. Copy button, progress, toasts, tables and accordions are built natively. Replaced by "Base UI for components" on 15 Nov.
Decided15 Nov
Installable web app on Windows and LinuxmacOS gets the native app. On Windows and Linux the web app installs as a progressive web app: own window, badge, push and an offline screen. It caches the app only, never data.
Decided15 Nov
Notifications are inFor a win, something that needs a person, a budget hit or a platform that needs attention; a run's end when asked. Native on the Mac, web push elsewhere, ids only. No email or chat for now.
Decided15 Nov
Base UI for componentsThe web client builds on Base UI (@base-ui/react, by the MUI team) instead of Radix. It has steady development and the parts our screens use that Radix lacks: combobox for Search, number field for budgets, meter. Each part is wrapped once in our components folder so features never import the library directly. Only what Base UI lacks is built natively.
Decided15 Nov
"Experiment" is the word users readThe thing a user creates and Ratchet works on is an experiment, on screen, in the CLI, the API and user docs. "Optimization" names only the basic: what better means. Never "automation".
Decided15 Nov
The Mac app updates with SparkleA direct download, signed with a Developer ID and notarized, updated with Sparkle. Not on the Mac App Store. Companies can still deploy it with their device management.
