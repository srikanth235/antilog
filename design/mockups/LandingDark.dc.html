Security

Built to pass your security review.

  • Your telemetry and code stay put

    Analysis runs in sandboxes. Antilog's server never connects to your data and never stores file contents, diffs or tool output.

  • Least access

    Agents get read-only credentials, and a short-lived git token that pushes only to their own branch.

  • Approvals and an audit log

    Anything that matters asks a person first, and every change and approval is logged: who, what, when.

  • Your sign-in

    GitHub or Google on Antilog cloud. Your own OpenID Connect provider when self-hosted.

  • Your cloud

    Antilog cloud runs on AWS. Self-hosting in your own AWS, Azure or Google Cloud account follows.

Questions

Questions engineering leaders ask first.

Will it break production?

No change ships without your developers' review, and every change must hold the quality requirements you set before you ever see it.

How is a saving measured?

The judge runs the new code and the code it started from side by side, repeatedly, on your code, and only counts a difference bigger than the noise. It is confirmed on data the agent never saw, measured offline, and watched after merge.

What does it cost to run?

Experiments spend tokens and compute inside the budget you set, and every experiment's cost is shown next to its result.

Which AI models does it use?

Agents on five platforms. Antilog picks by measured cost per verified improvement on your code, and says why. We publish no vendor benchmarks.

What do we need to start?

A repo, read access to your telemetry, and a cost you want lower.
